常見問題 (FAQ)

解答您在會議錄音與轉錄時可能遇到的疑問

❓ 電腦把喇叭關靜音或調整音量大小，會影響錄音嗎？

會的！因為 Windows 原生 Loopback 錄音是擷取送進喇叭端點的數位訊號。如果您將 Windows 工作列主音量調為靜音，錄出來的對方聲音也會變成無聲；若音量調小，錄進去的聲音也會同比例變小。
💡 最佳解法：插上耳機，電腦系統音量保持 80%~100%，透過「耳機線控上的實體滾輪」或硬體開關調小聲，這樣既不會吵到自己，電腦內部的錄音訊號依然是 100% 滿音量！

❓ 這台電腦沒有安裝 Python，可以使用嗎？

完全可以！下載的 Teams會議錄音與轉文字.exe 已經將所有音訊核心引擎、解碼器與介面全部封裝為獨立的單一執行檔，在任何乾淨的 Windows 10 或 11 電腦上雙擊即可直接運行。

❓ 除了 Teams 會議之外，支援 Zoom 或 Google Meet 嗎？

完全通用！本程式是直接擷取 Windows 系統的揚聲器輸出與麥克風輸入，因此無論您是使用 Teams、Zoom、Google Meet、Cisco Webex、Discord 或是 LINE 電腦版通話，皆能完美錄製與轉錄。

❓ 轉錄有檔案大小或長度限制嗎？

程式內建智慧串流分流技術：小於 15MB 的錄音檔會即時秒速編碼上傳；大於 15MB 的長會議（如 1~3 小時錄音）則會自動透過 Google File API 續傳通道上傳，支援最大達 2GB 的長錄音轉錄！
